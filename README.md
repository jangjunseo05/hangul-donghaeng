# 한글동행 · Hangul Donghaeng

Voice and photo assistance for exploring Korean food and culture, with grounded menu cards and a small curated place map.

Under active development for Agentic AI Hackathon 2026. No runtime validation is claimed yet. NVIDIA inference inside OpenShell, least-privilege policy evidence, and an end-to-end demo are release requirements.

The initial dataset covers one curated restaurant. It is not a nationwide restaurant search or an allergy-safety service. No booking, payment, or actual ordering is performed.

Implementation contract: [shared/api-contract.md](shared/api-contract.md).
