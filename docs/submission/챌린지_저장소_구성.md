# 공식 챌린지 저장소 구성·제출 호환성

확인: 2026-10-07. 담당 w1:pE. 공식 웹 README/TASK/입력 원문, GitHub API, root가 마련한 로컬 공개 입력을 읽었다. upstream main 커밋은 **714e2e8d32f9b77e763a2458ca11b1270e80abf6**. restricted/secrets 디렉터리 내용 미접근, 모델·GPU·제품 런타임 호출 없음. 아래는 검수 결과이며 fork/clone·통합·커밋은 root 담당이다.

## pN·pM 즉시 사용할 경로

**실재 확인한 허용 입력:** `<CHALLENGE_ROOT>/hackathon/input` (`CHALLENGE_ROOT`는 공식 fork의 로컬 clone 경로)

이 디렉터리만 읽는다. 파일은 20개, UTF-8 Markdown/TXT/CSV/JSON이다. 현재 제품의 요약된 `data/evidence.json`과 달리 원본 제공 입력 전체다. root의 복제 저장소 루트 전체를 재귀 입력으로 삼지 않는다. `restricted`·`secrets`는 형제 금지 영역이며 root MANIFEST에서 이름/해시가 보이더라도 읽기 허가가 아니다.

**해담 명칭:** 공개 입력에서 ‘해담문화원’은 발견되지 않았다. `misc/wifi_card_old.txt`에는 **해담문화관**의 2022년 Wi-Fi 안내만 있고 현재 사용 여부는 미확인이다. 이 메모를 문화원 운영·주소·역사·현재 통신 정보로 승격하지 않는다. 추가 평가 질문이 ‘해담문화원’을 요구하면 두 명칭을 합치지 말고 자료 부족/명칭 확인을 답한다.

## 경로·실행 진입점·fork 조건

| 구분 | 공식 확인 내용 | 통합 시 판단 |
|---|---|---|
| 루트 | README.md, TASK.md, MANIFEST.csv, .gitignore, hackathon/ | MANIFEST는 path,bytes,sha256 3열 CSV. 루트 목록에는 제공 실행기나 eval 스크립트가 없음 |
| 허용 입력 | 저장소 상대 `hackathon/input/`; 공통 테스트 런타임 `/hackathon/input` | pM이 읽기 전용 마운트/허용 정책을 명시. 로컬 상대 경로와 샌드박스 절대 경로를 혼동하지 않음 |
| 결과 | `hackathon/output/`에 .gitkeep; 공통 테스트 런타임 `/hackathon/output` | 산출물 쓰기 경로. 제품 HTTP 다운로드만 제공하는 경우 CLI 결과 파일과 매핑 필요 |
| 금지 | `/hackathon/restricted`, `/hackathon/secrets` | 내용·키·연락처 수집 금지. 이번 감사는 두 디렉터리를 열지 않음 |
| 공식 entrypoint | README/TASK에 고정 명령·함수명·CLI 인자·응답 JSON schema 지정 없음 | **agent/challenge.py는 pN이 만드는 팀 진입점**. root README에 실제 실행 명령, 입력/출력 인자, 의존성, 정책 적용 방법을 명시해야 함. 아직 명령 성공을 검증한 것은 아님 |
| fork/clone | 확인한 README/TASK에 **반드시 fork 또는 clone하라는 명시 문구 없음** | GitHub 저장소 제출과 제공 자료 요청 처리 요구는 있음. fork는 root의 통합 선택이며 공식 필수라고 단정하지 않음. 추가 현장 지시가 있으면 그 출처를 별도로 적용 |
| 제출 | 코드·OpenShell policy·README와 데모 URL/실행 방법·발표자료를 지정 Slack에 제출 | README: 소개, 설치/실행, 데모, 정책 경로, 권한 이유, 외부 API/서비스 허용 범위. 5분에 로딩·영상 포함. PDF/PPTX/로그인 없는 링크 허용 |

README와 TASK 어디에도 별도의 고정 평가 시나리오 파일명은 지정되지 않는다. TASK는 **연습 요청**이며 추가 평가 조건 가능. 따라서 연습 반나절 코스 하나만 하드코딩한 구현은 일반 제공 자료 질문 호환성을 입증하지 못한다.

## 요청 유형과 현재 제품의 호환성 주의

1. **공식 연습 요청:** 해담 옛시장·성진정 포함 해외 방문객 반나절 문화 코스 초안, 음식 제한·당일 운영 반영, 예약/발송 금지. 날짜·출발시각·체류시간을 구분하고 일정 산술이 맞아야 한다.
2. **공개 입력으로 가능한 추가 질문(우리 분석, 공식 확정 시험 아님):** 역사 연도 충돌, 같은 이름의 다른 사람, 시장 운영·공사·이동 경로, 음식 용어/제한, 무관 자료 제외, 외부 행동 승인 여부. 해담문화원처럼 없는 장소는 자료 부족으로 답할 수 있어야 한다.
3. **pN:** 기존 fictional_task 근거 9개 요약만으로는 OCR·community_board·동명이인·운영 메모 등을 빠뜨린다. 일반 CLI는 20개 허용 원본의 상대 경로를 근거로 보존하고 관련 자료를 선택해야 한다. 자료 문자열을 시스템 지시로 승격하지 않는다. 실행은 별도 검수 필요.
4. **pM:** CLI가 실제 `/hackathon/input`을 읽고 `/hackathon/output`에 결과를 쓰도록 실행 가이드·실효 정책·마운트를 맞춘다. CLI 명령이 있다는 사실만으로 OpenShell 안에서 실행됐다고 주장하지 않는다. 금지 형제 폴더를 자동 수집하는 재귀 탐색 금지.
5. **root:** 사용자가 확인한 실제 랜드마크→해설→식당 성공은 유지하되, 가상 공통 데이터 처리와 별도 시나리오로 표시한다. 공개 입력 패키지의 장소·기관·인물 등은 README가 가상이라고 명시하므로 실제 경복궁/광화문 정보와 합치지 않는다. fork+clone만으로 제공 자료 처리 완료가 되는 것은 아니다.

## 무결성 및 전달

입력 파일 SHA256을 루트 MANIFEST의 해당 20행과 비교했다. 아래 실측 결과의 LF 변환은 **메모리에서만** 수행했으며 원본 파일은 바꾸지 않았다. 원시 바이트가 달라지면 upstream 해시를 로컬 파일 실측 해시처럼 쓰면 안 된다.

- 원시 바이트 일치: 0/20. CRLF→LF 메모리 정규화 후 일치: 20/20.

Herdr의 실제 topology에서 w1:pN, w1:pM, w1:p7를 확인하고 명시적 팬으로 중간 결과를 전달했다. API는 agent_prompted를 반환했으며 이는 메시지 제출 확인이지 각 담당의 수용·통합 완료 증거는 아니다. 모델 호출·런타임 수정·Git 조작·금지 파일 열람 없음.
