# 문화 카메라 방향 P0 수용 체크리스트

상태: **검수 기준, 제품 실행 미검증** · 확인: 2026-10-07 KST · 미션: `day-of-v1-20261007`

## 고정 계약

- [공식 챌린지](https://github.com/seriousran/k-culture-openshell-challenge)의 한국 문화·역사·지역 맥락을 판단해 **실제로 쓰는 결과물**을 만든다. NVIDIA 에이전트 기술, OpenShell 구성 요소와 작동 데모가 필수다. 근거: 내부 제공 행사 PDF(비공개 정본) 4·5·12·13쪽, SHA-256 `9e65e79817324ac52f49666d214ce1d351cc8493b13bf5c96f1bc09352ff9fc0`; 제품 인터페이스는 [API 계약](../../shared/api-contract.md)을 따른다.
- 공통 자료는 `/hackathon/input`에서 필요한 것만 읽고 결과는 `/hackathon/output`에 쓴다. `/hackathon/restricted`·`/hackathon/secrets`는 접근 금지다. 제공 지명·기관은 가상일 수 있으므로 실제 장소로 억지 연결하지 않는다.
- 공식 배점은 NVIDIA 기술 **40**, 실용성·가치·혁신성 **20**, 완성도 **20**, 발표 **10**, 동료평가 **10**이다. peer 점수는 `null`; PDF와 최신 공지의 세부 환산 차이는 미확인이다.
- **16:00 KST는 사용자 지정 개발·검증·인계 마감**, **17:20 KST는 공식 제출 마감**이다. 발표와 작동 데모 합계는 **5분**이며 로딩도 포함한다. 내부 PDF 13쪽의 영상은 **선택 자료**로 작동 데모를 대체하지 않는다.

## P0 — 하나라도 빠지면 카메라 방향 완료 주장 금지

| 항목·담당 | 관찰 가능한 통과 기준 | 남길 증거 |
|---|---|---|
| [ ] **실시간 프레임 분석·캡처** — p8 | 카메라 허용 후 미리보기가 동작한다. 사용자가 주기 분석을 켜면 **서로 다른 두 프레임**의 `frame_id`·시각·결과가 자동 갱신되고 명시적 정지로 멈춘다. 자동 요청은 한 번에 하나, 수동 캡처 우선, 반복 요청 방지. 캡처 이미지와 그 분석은 같은 프레임 ID에 묶는다. 권한 거부·카메라 없음·늦게 도착한 응답은 오류/보류로 표시한다. 연속 영상 전체 전송·저장이나 정지 사진 수동 업로드만으로 통과 처리하지 않는다. | 두 프레임 ID·시각·캡처 해시·화면 기록, 정지/거부 장면. |
| [ ] **문화유적 → 식당** — pN·pE | 유적 프레임과 사용자 조건을 받아 공통/허용 자료의 식당·음식 정보와 대조한다. 역사·지역 연결 및 식사 조건의 **출처 있는 이유**를 제시하고 영업·이동·재료 정보가 없으면 미확인으로 둔다. 관찰 대상이 불명확하면 단정 추천하지 않는다. | 프레임 ID → 근거 ID·시점 → 선택/보류 → `/hackathon/output`의 방문·식사 카드 또는 일정 파일. |
| [ ] **식당 → 문화유적** — pN·pE | 다른 식당/메뉴 프레임에서 출발해 관련 유적·문화 체험을 찾는다. 단순 역순 하드코딩이 아니라 **새 관찰과 자료**로 연결 이유를 재판단한다. 문화 연결 근거가 없거나 운영 정보가 불명확하면 질문/보류한다. | 반대 방향의 별도 프레임 ID·근거·선택/보류 로그와 산출 파일. 같은 고정 문구 재사용이 아님을 확인. |
| [ ] **맥락·신뢰 반례** — pE·pN | 최신·오래된·상충 자료 한 묶음과 무관 자료 한 건으로 출처/적용 시점을 구분해 결과를 바꾸거나 보류한다. 화면 추정만으로 가상 지명을 실제 장소로 확정하지 않는다. 알레르기·의료·법률 안전을 확정 판단하지 않는다. | 반례 전후 결과 diff, 주장별 출처/미확인 표, 무관 자료 제외 이유. |
| [ ] **실제 NVIDIA + OpenShell** — pN·pM·root | NVIDIA 추론이 프레임/자료 판단에 실제 사용되고 요청·응답 식별자, 모델/제공자, 실패 경로가 남는다. OpenShell **실효 정책**에서 허용 입력 읽기·출력 쓰기·필요 네트워크만 확인한다. 정상 흐름과 금지 파일·미승인 네트워크·삭제 시도의 **실제 차단**을 폐기 가능한 허용 시험 환경에서 검증한다. 금지 파일 내용 열람이나 실제 자원 삭제는 금지. 출력 폴더 `read_write`만으로 삭제 방지를 입증하지 않는다. | 정책 파일·실효 정책·정상 로그·거부 로그·산출 파일. 미실행이면 `unverified`. |
| [ ] **끝까지 재현·제출** — root | 15:00 기능 동결, 15:30 핵심 검증, 16:00 인계라는 제품 저장소 마감을 따른다. 정상·반례·거부 흐름을 실제 재실행한다. 17:20 전 공개 제품 저장소의 코드·정책·README, 데모 링크/실행법, 발표자료를 제출 대상으로 준비한다. 5분 안에 프레임 변화→양방향 판단→출력→OpenShell 경계를 보여준다. | 재실행 기록, 제출물 목록, 5분 리허설 실측. 제출·리허설 전에는 PASS로 쓰지 않음. |

**root 판단이 필요한 차단 조건:** 16:00까지 실제 카메라 프레임→NVIDIA 판단이 연결되지 않거나, 양방향 중 한쪽의 공통 자료·문화 연결 근거가 없거나, OpenShell 정상/거부 실행을 보일 수 없으면 **P0 미충족**이다. 고정 화면 결과·선택 영상·과거 PDF 수치를 작동 증거로 대체하지 않는다. 기능 축소 또는 제출 범위는 root가 결정한다.
