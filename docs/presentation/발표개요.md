## 한 문장 메시지

여행자가 한국의 거리와 장소를 보는 동안 선택한 장면을 관찰해 먼저 확인 질문·제안을 건네고, 질문이 오면 현재 장면을 기준으로 한글 장소명·역사 근거·모름·주변 식사를 연결한 동행 카드를 만드는 것이 목표다.

이 문장은 **제품 목표**다. 12차 실제 UI에서 사진 질문→USER 광화문 카탈로그 확인→문화 맥락→근처 식당 지도→HTML/JSON 다운로드가 3단계 PASS다. 이 범위만 문화 경로의 실제 동작으로 말한다.

## 보여 줄 사용자 경험과 구현 경계

1. **문제:** 처음 보는 경복궁·광화문 주변 장면의 한글 이름, 역사 맥락, 다음에 갈 곳을 한 번에 이해하기 어렵다. PDF 1장의 2025년 방한 외래객 18,936,562명(한국관광공사 2025 관광통계)은 시장 규모 배경이며 제품 수요·성과 실증으로 말하지 않는다.
2. **카메라 설계:** 화면의 연속 미리보기는 로컬이다. 영상의 목표 가치는 선택된 장면을 선제 관찰해 확인 질문·제안을 건네는 데 있다. 사용자가 켠 경우에만 선택적 프레임 분석을 **최소 20초 간격**으로 계획한다. 화면 표시와 모델 분석 주기를 분리해 설명하며, 전송·저장 경계의 구현과 QA는 별도 확인이 필요하다.
3. **대화 설계:** 장소 후보가 불확실하면 에이전트가 자발적으로 확인 질문·제안을 한다. 실시간 질문 시 현재 프레임 자동 캡처와 명시 고정 유지가 p8에서 구현 중이다. 수동 캡처는 손편의를 위한 선택지다. 현재 기억은 마지막 사진과 최근 수동 대화만이며 전체 영상 기억·최근 장면 메모리는 없다.
4. **근거 판단:** 역사·문화 문장은 확인된 출처 ID, 대상·시점과 함께 보여 주고 충돌하거나 근거가 부족하면 모름으로 남긴다. PDF 4장은 한국관광공사 VISITKOREA를 근거로 광화문이 경복궁 남쪽 정문이고 세 홍예문 중 가운데 문이 왕의 역사적 통로였다고 제시한다. 이를 현재 출입 규칙으로 옮겨 말하지 않으며 앱 답변과 출처 일치는 별도로 검수한다.
5. **다음 행동:** 문화 장소→등록된 근처 식사를 우선 흐름으로 제시한다. PDF의 양방향 화살표는 목표 연결이며 역방향 11 API는 unknown_menu 실패 후 수정 중이므로 작동 완료로 말하지 않는다. 데이터가 없는 곳은 결과 없음으로 표현한다.

## 예상 질문 5개

1. **왜 영상인가? 사진 한 장이면 되지 않나?** 목표 가치는 선택된 장면을 보고 먼저 확인 질문·제안을 하는 것이다. 질문 시 현재 프레임 자동 캡처와 선택적 수동 고정은 구현 중이다. 현재 전체 영상·최근 장면 기억은 없고, 자동 관찰도 QA 전까지 실증이 아니다.
2. **장소 이름이 틀리면?** 사진만으로 단정하지 않고 경복궁·광화문 같은 후보를 확인 질문으로 제시한다. 위치·장면이 맞지 않으면 모름을 남긴다.
3. **역사 설명을 어떻게 믿나?** 문장에 맞는 출처 ID·대상·시점을 확인한다. 근거가 없거나 충돌하면 사실로 단정하지 않고 확인 질문으로 돌린다.
4. **식사와 문화 장소가 모두 연결되나?** 12차 실제 UI에서 문화 장소→근처 식당 지도·HTML/JSON은 PASS다. 역방향은 12차 미실행이고 11차 unknown_menu 실패를 수정 중이다. 식당 메뉴 4단계도 historical_source_mismatch로 실패해 전체 UI 완료는 주장하지 않는다.
5. **무엇이 실제 작동했나?** 기존 음식 사진·근처·카드 저장, 실제 GPU 모델 호출, 통제 OpenShell 차단이 확인됐다. 07 문화 observe GPU는 evidence_scope_mismatch로 실패해 pN이 수정 중이다. 새 문화 경로의 기능·시간은 최종 QA가 통과하기 전까지 실증이라고 말하지 않는다.
