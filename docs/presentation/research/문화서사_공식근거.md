# 문화 서사: 광화문을 한글로 풀어주는 가이드

확인일: 2026-10-07 (KST). 발표용 문장 후보이며, 아래 세 근거는 역사 사실을 뒷받침한다. 앱의 사진 인식 정확도·방문객 수요·현장 운영 상태를 입증하지는 않는다.

| **“광화문은 경복궁의 남쪽 정문이고, 세 홍예문 가운데 문은 왕이 지나던 통로입니다.”** | 한국관광공사 [VISITKOREA 광화문 소개](https://english.visitkorea.or.kr/svc/whereToGo/locIntrdn/rgnContentsView.do?vcontsId=110592)의 위치·세 문 통행 설명. 영문 원문을 한국어로 의역했다. 역사적 통행 구분이지 오늘날 출입 규칙이 아니다. |
| **“1395년에 세워진 경복궁의 이야기를, 여러 차례 손상·복원을 겪어 2010년 8월 15일 공개된 정문 광화문에서 시작합니다.”** | [서울관광재단 Visit Seoul 경복궁](https://english.visitseoul.net/PalaceArea/Gyeongbokgung-Palace/ENP000072)은 궁궐의 1395년 건립·조선 중심 궁궐을, 위 한국관광공사 광화문 원문은 문 복원 후 공개일을 설명한다. 두 대상을 같은 건물로 합치지 않는다. 두 페이지 모두 영문을 한국어로 의역했다. |
| **“한글동행은 한자 현판 ‘光化門’을 한글 유물로 오인하지 않고, 그 문이 품은 역사를 쉬운 한글과 출처로 설명합니다.”** | [국립한글박물관 상설전시 ‘훈민정음, 천년의 문자 계획’](https://www.hangeul.go.kr/exhi/dailyExhibition.do?curr_menu_cd=0102010000)은 한글의 쉬운 소통·지식 전달 취지를 설명한다. **현판은 한자이며 한글은 우리 서비스의 설명 언어**다. 박물관 자료는 광화문 현판의 글자 모양이나 앱의 효과를 검증하지 않는다. 데모 사진에서 ‘光化門’ 판독 여부는 원본 화면으로 별도 확인한다. |

발표 적용: 사진을 보여 주고 **“광화문일 수 있습니다. 먼저 확인해 주세요”**라고 말한 뒤, 확인된 장소에만 위 사실·출처를 붙인다. 세 홍예의 역할과 복원 이력을 한 장에 배치하고, 한자 현판→쉬운 한글 설명을 제품 동작으로 보여 준다. 광화문은 경복궁의 **일부인 정문**이므로 두 독립 유적을 방문하는 것처럼 세지 않는다.

피할 표현: “사진만으로 광화문 확정”, “현판에 한글이 쓰여 있다”, “세종이 광화문 현판을 만들었다”, “현재 개방·입장 가능”, “관광공사가 이 앱을 추천/검증했다”. 이번 출처 확인은 문헌 사실에 한정하며, 현장 촬영·GPS·당일 운영·모델 답변의 실측 검증과 구분한다.
