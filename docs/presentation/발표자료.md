# 한글동행 발표 대본 — 현재 상위 PDF 7장 대응

기준: 한글동행_발표_근거반영.pdf(7페이지). 화면의 정확한 문구는 발표자료_PDF본문.md에 전사했다. 아래는 페이지 순서에 맞춘 발표자 대본이다. 발표 300초 중 5장 목표 데모 90초. 문화 장소→주변 식사를 우선 시나리오로 말하며, 각 동작의 실제 통과 여부는 ROOT 최종 QA로 확정한다. 전체 Android UI 동작을 완료로 주장하지 않는다.

## 1. 한글로 잇는 한국의 문화와 역사 (0–20초, 20초)

**PDF 화면:** 한글동행 · 한글날 기념 프로젝트. 경복궁, 광화문, 골목의 식당. “한글 이름과 역사 맥락을 묻고, 다음 걸음을 정합니다.” 2025년 방한 외래객 18,936,562명. 시장 규모 배경 출처는 한국관광공사 2025 관광통계이며 제품 수요 실증과 구분한다.

**발표 대본:** “한국을 걷는 여행자가 눈앞의 장소를 보고 한글 이름과 역사 맥락을 묻습니다. 한글동행은 그 장소에서 주변 식사까지 잇는 동행을 목표로 합니다. 2025년 방한 외래객 18,936,562명은 관광시장 규모의 배경이지 이 제품의 수요 실증은 아닙니다.”

**근거 노트:** 경복궁·광화문은 발표의 탐색 후보이며 장면 인식 성공이나 사용자 수요 실측으로 말하지 않는다.

## 2. 보는 화면은 연속, 분석은 선택적으로 (20–50초, 30초)

**PDF 화면:** 로컬 연속 미리보기, 선택적 분석 최소 20초 간격, 선제 확인 질문, 질문 시 현재 프레임 자동 캡처, 장면 고정은 선택. 실제 앱 화면 두 장은 각각 카메라 시작 전과 경복궁 출발점 선택·분석 미실행 상태다.

**발표 대본:** “Android에서 후면 카메라 미리보기와 촬영 중단 뒤 캡처 유지가 사용자에게 확인됐습니다. 영상의 목표 가치는 선택된 장면을 보고 먼저 질문을 제안하는 데 있습니다. 분석은 켠 경우 최소 20초 간격으로 계획했고, 질문 시 현재 프레임 캡처와 명시 고정은 구현·검증 중입니다.”

**근거 노트:** 실제 앱 이미지의 ‘분석 미실행’을 분석 성공 화면으로 소개하지 않는다. 자동 프레임·선제 질문·Android 음성은 아직 미검증이다. 현재 기억은 마지막 사진과 최근 수동 대화뿐이며 전체 영상·최근 장면 메모리는 없다.

## 3. 모델이 판단하고, 정책이 경계를 정합니다 (50–90초, 40초)

**PDF 화면:** 브라우저 → trusted broker ↔ OpenShell worker ↔ NVIDIA L40S. Nemotron Nano 12B v2 VL BF16, vLLM 0.12.0. worker는 구조화 안내를 반환하고 broker가 근거·형식·좌표·소유권을 검사해 사용자별 여행 카드를 영구 저장한다. 개발 중인 호출 조건은 20초 이상 간격과 이전 응답 완료 후 다음 분석이다. PDF 출처 표기는 NVIDIA 모델 카드·OpenShell 정책 문서이며 개별 호출 확인과 통합 흐름 검증을 구분한다.

**발표 대본:** “기존 사진 경로에서 실제 NVIDIA GPU 모델 API 응답과 OpenShell worker 호출을 확인했습니다. worker는 장면 후보와 도구를 판단해 구조화 안내를 돌려주고, trusted broker가 결과와 소유권을 검증해 영구 카드를 저장합니다. PDF의 주기 분석·선제 질문은 아직 통합 검증 중입니다.”

**근거 노트:** 기존 사진 경로의 성공을 새 문화 경로 전체 PASS로 바꾸지 않는다. 07 문화 observe GPU 요청은 evidence_scope_mismatch로 실패했고 pN이 수정 중이다. 모델 단독 지연 수치를 만들지 않는다.

## 4. 문화·역사 설명도 출처에서 시작합니다 (90–120초, 30초)

**PDF 화면:** 한국관광공사 VISITKOREA 광화문 설명에 따르면 광화문은 경복궁의 남쪽 정문이고 세 홍예문 중 가운데 문은 왕이 지나던 역사적 통로다. 이는 현재 출입 규칙이 아니다. 장소 후보·위치·질문을 함께 보고 불확실하면 확인하며, 설명에 출처와 시점을 남긴다. 근거가 부족하거나 충돌하면 모름과 질문을 남긴다.

**발표 대본:** “광화문이 경복궁 남쪽 정문이고 가운데 홍예문이 왕의 통로였다는 설명은 PDF에 적힌 한국관광공사 VISITKOREA 근거를 따릅니다. 과거 통행 설명을 현재 출입 규칙으로 말하지 않습니다. 실제 장면의 장소 후보와 문장 근거가 맞지 않으면 모름과 확인 질문을 남깁니다.”

**근거 노트:** PDF에도 문화·역사 답변의 의미와 출처 일치 검수 중이라고 표시돼 있다. 검수되지 않은 역사 사실이나 출처 ID를 현장에서 만들어 말하지 않는다.

## 5. 문화 장소에서 식사까지: 목표 데모 (120–210초, 90초)

**PDF 화면:** “이곳에는 어떤 이야기가 있나요? 주변에서 식사할 곳도 함께 알려 주세요.” 장면 보고 질문 → 문화 장소 ↔ 식당 → 동행 카드 저장. 임시 HTTPS 링크는 터널이 실행 중일 때만 유효하다. 전체 Android 흐름의 완료 검증은 진행 중이다.

**발표 대본과 90초 배분**
- **120–135초:** “이 화면은 확인된 Android 카메라 화면입니다. 분석 미실행 캡처와 새 문화 경로의 결과를 구분해 보겠습니다.” 선택적 분석 설정을 설명한다.
- **135–155초:** 실제 동작이 QA를 통과했다면 선제 질문이나 현재 프레임 질문을 보여 준다. 그렇지 않으면 PDF의 목표 흐름으로 소개하고 동작 완료라 말하지 않는다.
- **155–180초:** 검증된 장소 후보와 역사 출처·모름이 있으면 제시한다. 없으면 관측·근거·확인의 판단 기준을 설명한다.
- **180–195초:** 우선 흐름인 문화 장소→등록된 주변 식사를 설명하거나, QA를 통과한 결과만 시연한다.
- **195–210초:** trusted broker가 검증·저장한 해당 결과 카드가 확인됐다면 연다. 기존 음식 카드만 있다면 ‘기존 음식 경로의 카드’라고 밝힌다.

**근거 노트:** PDF의 ↔는 목표 연결이다. 식당→문화 장소 역방향 11 API는 unknown_menu로 실패해 수정 중이므로 라이브 성공·완료로 말하지 않는다. 전체 Android UI 종단 시연도 미검증이다. 90초는 무대 편성 시간이며 처리 성능 보장이 아니다. 기존 음식 사진 9.25초·근처 21.48초는 그 경로의 개별 종단 관측으로만 사용한다. 사전 실행 화면은 사전 결과라고 밝힌다.

## 6. 허용과 차단을 실제 기록으로 확인했습니다 (210–260초, 50초)

**PDF 화면:** 허용된 GET 200, 예약 POST 403·수신 0, 비허용 목적지 수신 0, 제한 파일 읽기·쓰기·삭제 시험 차단과 보호 파일 전후 해시 동일. OpenShell 0.1.2의 자체 통제 시험 범위다. PDF 출처 표기는 NVIDIA OpenShell 보안 가이드·제품 시험 기록이며 새 프레임 경로의 실효 정책은 별도 검증 대상이다.

**발표 대본:** “에이전트에는 필요한 경로만 허용했습니다. 통제 시험에서 허용된 상태 조회는 200이었고, 허용하지 않은 예약 전송은 403과 수신 0을 확인했습니다. 제한 파일 동작도 차단되고 보호 파일의 전후 해시는 같았습니다. 자체 무해한 시험과 정책·수신 기록의 대조이며, 모든 경로가 안전하다는 뜻은 아닙니다.”

**근거 노트:** 기존 통제 시험 ID A11/A12는 내부 근거다. 새 카메라 프레임 경로의 실효 정책을 별도로 검증해야 한다. audit를 차단으로, read_write를 모든 삭제 방지로 설명하지 않는다. 원시 로그·비밀값은 화면에 싣지 않는다.

## 7. 한국의 문화와 일상을 한글로 이어 갑니다 (260–300초, 40초)

**PDF 화면:** 확인된 개별 동작은 실제 모델 API 응답 완료와 Android 카메라·캡처 유지다. 주기 분석·선제 질문·문화 답변은 검수 중이고 전체 Android 시연도 미검증이다. 경복궁·광화문, 출처와 함께 이해할 역사 맥락, 문화 장소와 주변 식사가 결말이다.

**발표 대본:** “오늘 확인한 것은 실제 모델 API의 개별 응답과 Android 카메라·캡처 유지입니다. 주기 분석과 선제 질문, 역사·문화 답변의 검수는 계속하고 있습니다. 한글동행의 목표는 장소의 한글 이름과 출처 있는 맥락을 이해하고 주변 식사로 이어 가는 것입니다. 완료되지 않은 전체 Android 흐름을 완료로 말하지 않겠습니다.”

**근거 노트:** 역방향 식당→문화 장소는 unknown_menu 수정 중이며 PDF의 양방향 표기는 목표다. 현재 기억은 마지막 사진+최근 수동 대화로 제한된다. 사용자 수요·정확도·속도 향상 수치를 만들지 않는다.

## ROOT 최종 QA 교체 조건

문화 장소→주변 식사, 역사 문장·출처, broker 저장 카드, 07 문화 GPU 수정, 11 API 역방향 수정, 전체 Android UI를 각각 별도 결과로 받는다. 통과한 항목만 해당 페이지 대본의 조건문을 실제 동작 설명으로 바꾼다. 7장 300초와 5장 90초는 유지한다.
